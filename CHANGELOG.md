# Changelog

All notable changes to the RevenueAI project are documented in this file.

## [0.3.0] - 2026-09-04
### Added
- Notification preview modal supporting multi-channel template switching (Email, SMS, WhatsApp).
- Field agent & desk cash settlement reconciliation with instant receipt generation.
- Real-time Email Sandbox inbox view with SPF/DKIM verification details.

### Fixed
- Fixed lazy initialization for Razorpay gateway SDK to prevent Vercel build failures.

## [0.2.0] - 2026-08-29
### Added
- Integrated Google Gemini 2.5 Flash for automated failure diagnosis and channel recommendation.
- Added multi-channel notification dispatcher for transactional email and SMS text.

## [0.1.0] - 2026-08-29
### Added
- Initial project scaffolding with Next.js 16, Prisma SQLite ORM, and Razorpay checkout engine.
