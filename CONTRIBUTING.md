# Contributing to RevenueAI

Thank you for your interest in improving RevenueAI!

## Development Workflow

1. **Fork the repository** on GitHub.
2. **Create a feature branch**:
   ```bash
   git checkout -b feature/recovery-enhancement
   ```
3. **Commit conventions**:
   Please follow the Conventional Commits standard:
   - `feat:` for new capabilities
   - `fix:` for bug fixes
   - `docs:` for documentation updates
   - `test:` for test additions or updates
   - `refactor:` for internal code cleanups
4. **Run build check**:
   ```bash
   npm run build
   ```
5. **Open a Pull Request** describing your changes.
